# 🌱 CarbonWallet

Track your carbon footprint with every transaction!

## 🚀 Quick Start

### Installation
```bash
# Install dependencies
npm install
```

### Run the App
```bash
# Start development server
npm start
```

The app will open at `http://localhost:3000`

### Build for Production
```bash
npm run build
```

## 📦 Project Structure

- `src/App.js` - Main application component
- `src/components/LoginPage.js` - Login interface
- `src/components/Dashboard.js` - Main dashboard
- `src/components/utils.js` - Helper functions and data

## 🎯 Features

- ✅ User authentication
- ✅ Daily/Weekly/Monthly carbon tracking
- ✅ Green points reward system
- ✅ Category-wise emissions
- ✅ Beautiful UI with Tailwind CSS

## 🛠️ Technologies

- React 18
- Tailwind CSS
- Lucide React Icons
